# Turnitin

> Turnitin is an academic and research integrity company. For 20+ years it has
> delivered plagiarism/similarity checking, AI-writing detection, grading and
> feedback tooling for educators, researchers, and publishers. Its Turnitin Core
> API (TCA) lets third-party platforms submit a file, generate a Similarity
> Report, and display it to users without leaving the host platform.

This file was generated by the API Evangelist enrichment pipeline from the
public Turnitin developer documentation and this repository's artifacts. The
full TCA API Reference is behind a customer login; values here come only from
publicly reachable pages.

## APIs

- [Turnitin Core API (TCA)](https://developers.turnitin.com/turnitin-core-api): RESTful API for integrity services — submit documents, generate Similarity Reports, retrieve results. Auth: integration-instance API key via header, plus X-Turnitin-Integration-Name / X-Turnitin-Integration-Version headers. SOC2 compliant, international data centers.
- [Learning Tools Interoperability (LTI)](https://developers.turnitin.com/learning-tools-interoperability): LTI integration path for LMS platforms (alternative to TCA REST).
